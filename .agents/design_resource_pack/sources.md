## Interpretation rule

A social post can suggest a direction, a community file can reveal a reusable pattern, and a first-party guideline can establish a constraint. The final design rule should be grounded in the latter whenever the sources disagree. Avoid copying brand-specific assets, proprietary imagery, or exact visual identity; extract principles, tokens, interaction logic, and implementation patterns instead.

## Source-handling note

Platform search results for TikTok, Instagram, and YouTube are often incomplete or dynamically rendered. The pack therefore records stable public links and the extraction purpose rather than inventing engagement rankings. “High-star” GitHub labels should be rechecked at installation time because stars and maintenance status change. Community skills and MCPs must be reviewed for security, permissions, network calls, and prompt-injection risk before use.
