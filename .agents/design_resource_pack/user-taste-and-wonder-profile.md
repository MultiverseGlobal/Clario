# User Taste and Wonder Profile

Apply this profile as a design preference layer for this project. It is based only on the user’s expressed requests in this workspace and should remain subordinate to accessibility, product requirements, technical constraints, and evidence.

## Observed priorities

The user cares deeply about visual taste, premium craft, immersive interfaces, motion, Apple-inspired clarity, glass and material systems, page layout, user flow, UX quality, cross-device behavior, reusable components, design ecosystems, and the ability of the agent to think beyond the literal prompt. The user does not want generic AI-looking output or a design that works only on one PC screen. The user wants the agent to make software design simpler while producing work that feels distinctive, considered, ambitious, and memorable.

The user values **wonder**, but not spectacle for its own sake. Wonder should come from a surprising but useful interaction, a beautiful transition, a precise visual metaphor, a tactile state change, a strong typographic moment, an elegant data story, or an interface that makes a difficult task feel unexpectedly clear.

## How to apply this profile

Start with a product-specific point of view. Choose one memorable signature and make it excellent. Use immersive components when they support comprehension, trust, delight, or emotional connection. Keep the surrounding interface disciplined so the signature has room to matter.

Think beyond the immediate request. Identify likely downstream problems in information architecture, user flow, accessibility, responsiveness, performance, content, maintenance, and licensing. Explain the concern and propose a better route. Do not silently override the user’s business goal or core brand direction.

When presenting alternatives, show meaningful differences rather than five cosmetic variations. Recommend one option and explain why it best balances taste, usability, differentiation, and implementation risk. Prefer a smaller number of strong decisions over an overloaded style collage.

## Taste calibration questions

Before implementation, ask: What belongs specifically to this product? What will users remember? What is the first focal point? Is it the right one? Does the interaction have a reason to move? Is the glass or glow doing semantic work? Is the typography carrying enough personality? Where might the user hesitate? What will break on a phone, keyboard, screen reader, low-power device, or reduced-motion setting? What can be removed without reducing meaning?

## Personalization boundaries

Do not infer private identity, finances, psychological traits, or unspoken business goals. Use this profile only for design quality, strategic challenge, taste, wonder, and cross-device craft. When a preference conflicts with the needs of users, accessibility, safety, performance, or legal licensing, explain the tradeoff and prioritize the responsible implementation.

## Definition of success

The result should feel like a product with a point of view, not an AI assembling popular effects. It should be beautiful in a screenshot, but also clear in use, robust across devices, accessible without the effects, fast enough to feel immediate, and maintainable as the ecosystem grows.
