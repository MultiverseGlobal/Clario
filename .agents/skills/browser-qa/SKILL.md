description: Use for browser verification of web product behavior, routes, forms, keyboard interaction, accessibility structure, and network-backed states.
---

Use the project’s browser verification workflow and `@50-quality-gate.md`. Inspect the rendered app rather than trusting code. Verify routes, links, buttons, forms, loading, empty, error, success, authorization, keyboard, focus, responsive widths, and console/network failures. Report evidence and do not claim a pass without actually checking it.
