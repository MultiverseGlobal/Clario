Read and apply `@database-api-backend.md`, `@platform-architecture.md`, and `@reliability-security-performance.md`. Inspect actual schema, migrations, server helpers, routers, environment access, and client hooks. Follow schema or contract → migration → server → API → client → UI states → tests. Validate input and authorization on the server. Never invent a route, field, procedure, secret, or data source.
