# Pseudonyms Local Skills

These local skills are thin, project-specific activation layers over the detailed Markdown rules in `.agents/rules`. They are intentionally small so Antigravity can load the right capability without creating context soup.

| Skill | Use when |
|---|---|
| `pseudonyms-design` | Any Pseudonyms product or ecosystem interface. |
| `taste-engine` | Any visual design, redesign, layout, or polish task. |
| `expo-mobile` | Expo, React Native, Expo Router, NativeWind, or mobile interaction. |
| `full-platform` | Cross-client product planning and architecture. |
| `browser-qa` | Browser behavior, route, form, keyboard, and accessibility verification. |
| `visual-qa` | Screenshot-grounded layout, responsive, motion, and visual review. |
| `backend-contracts` | Database, API, authentication, authorization, integrations, or migrations. |

Every skill must verify current repository facts before making claims. No skill overrides product requirements, security, accessibility, or the adoption rule.
