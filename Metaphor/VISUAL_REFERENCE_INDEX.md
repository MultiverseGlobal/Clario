# Metaphor Visual Reference Index

## 1. Composition Archetypes

1. **Floating Glass Capsule**:
   - Fixed at `top: 32px`, centered horizontally.
   - Height: `52px`, pill radius (`rounded-full`), `backdrop-blur-xl`.
   - Subtle hairline border: `1px solid rgba(10, 10, 10, 0.06)`.
   - Contains Metaphor emblem + minimal section links.

2. **Bare Underline Form Fields**:
   - Zero background box, zero rectangular borders.
   - Text centered or left-aligned with a bottom hairline border (`1px solid rgba(10, 10, 10, 0.15)`).
   - Placeholder text rendered in `Cormorant Garamond` italic.
   - Focus transitions border color smoothly to `var(--color-ink)`.

3. **Hairline Divided Tables & Timelines**:
   - Replaces heavy, padded cards.
   - Content separated only by `1px solid rgba(10, 10, 10, 0.06)` dividers.
   - Hover reveals a gentle `rgba(0, 0, 0, 0.01)` wash with `-mx-3 px-3` rounded boundary.

4. **Participant Matrix**:
   - Minimal cards on translucent background (`rgba(255, 255, 255, 0.60)`).
   - Official monochrome brand SVG icons centered in subtle square containers.
   - Monospace latency badges (`22ms`, `45ms`) with emerald indicator dots.
